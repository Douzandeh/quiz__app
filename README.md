# 🎮 Quiz App

A modern and interactive online quiz application built with HTML, CSS, and JavaScript.

## ✨ Features

- Clean and responsive user interface
- 10 multiple-choice questions fetched from OpenTDB API
- Visual feedback for correct and incorrect answers (Green / Red)
- Shows the correct answer when the user selects a wrong one
- Real-time score tracking
- Animated loading spinner
- Multiple pages: Home, Game, and High Scores (ready for future expansion)

## 🛠️ Technologies Used

- HTML5
- CSS3 (with modern styling and hover effects)
- Vanilla JavaScript (ES6+)
- Fetch API
- Responsive Design
